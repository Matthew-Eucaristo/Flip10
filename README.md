# Flip10

A focused offline Shut the Box dice game built with Flutter for Android, iOS,
and web. One player, ten tiles, two dice, unlimited rounds. Hand-drawn SVG
art, procedural audio, installable PWA.

## Gameplay

- Roll two dice, then close any combination of open tiles whose digits sum to
  the roll (7 + 3, or 1 + 2 + 7, or just a single 7, etc.).
- If no legal combination exists, the round is blocked and the sum of all
  remaining open tiles is added to your running total.
- Close every tile (1-10) in a single turn to "shut the box" — perfect round,
  nothing added to the total.
- After a round, tap **Play again** to start the next round (total is kept)
  or the **New game** icon in the active-player band to reset the total.

## Stack

- Flutter Material 3 app shell
- Pure Dart game rules (`lib/src/game/game_rules.dart`) and turn state
  (`lib/src/game/game_models.dart`, `game_controller.dart`)
- Local settings persistence with `shared_preferences` (PWA install banner state)
- `flutter_svg` for inline SVG art; custom audio service:
  `audioplayers` on Android/iOS/desktop, raw `HTMLAudioElement` on web
  (the `audioplayers_web` event channel is broken on current Flutter web)
- Installable web build (PWA with manifest + service worker + custom
  `beforeinstallprompt` banner via `dart:js_interop`)
- All tile/dice/icon SVG art and procedural audio WAVs generated by Python
  tools in `tools/`


## Code layout

```
lib/
  main.dart                          # entry
  src/
    app/flip10_app.dart              # MaterialApp shell
    game/
      game_models.dart               # GamePhase, DiceRoll, PlayerBoard, GameSnapshot
      game_rules.dart                # pure rules: legal moves, blocked, isShut
      game_controller.dart           # newGame(), nextRound(), roll, toggleTile, ...
    ui/
      game_screen.dart               # LayoutBuilder phone vs desktop
      board/                         # BoardTable, TileRack, DiceRow, NumberTile,
                                     # MoveHints, ActionPrompt, ActionRow,
                                     # ActivePlayerBand (with New game icon)
      common/                        # SvgIcon, BrassPlate
      feedback/                      # Haptics, Audio (abstract + native + web),
                                     # PwaInstallBanner (web + stub)
      header/                        # BrandMark, GameHeader (brand only)
      theme/flip10_colors.dart       # palette
```

`GameSnapshot` is immutable; the controller emits a fresh snapshot on every
state change and the UI rebuilds via `ListenableBuilder`. The constants
`kTileCount` and `kDiceCount` in `game_models.dart` are the single source of
truth — change them in one place to ship a different variant.

## Visuals & assets

Hand-drawn SVG art is the source of truth for every visual element. Tiles
bake their number as a `<path>` glyph (not `<text>`) so rendering is identical
across platforms, including the Flutter test environment (which uses the Ahem
fallback font). The full asset pipeline is reproducible:

| What              | Source                                            | Output                                                          |
|-------------------|---------------------------------------------------|-----------------------------------------------------------------|
| Brand mark        | `assets/svg/misc/brand-mark.svg` (hand-authored)  | `web/favicon.svg` + `web/icons/Icon-*.png`                      |
| Wood frame, felt  | `assets/svg/board/` (hand-authored)               | inlined via `SvgIcon`                                           |
| Tiles             | `tools/gen_tiles.py`                              | `assets/svg/tiles/tile-{ivory,selected,hinted}-{1..10}.svg`, `tile-closed.svg`, `tile-mini-*.svg` |
| Dice faces        | `tools/gen_dice.py`                               | `assets/svg/dice/face-{1..6}.svg`, tumble variants, `face-blank` |
| Phase / medal art | `assets/svg/misc/`                                | inlined via `SvgIcon`                                           |
| Audio cues        | `tools/gen_audio.py`                              | `assets/audio/{roll,flip,success,blocked}.wav`                  |
| PWA icons         | `tools/gen_icons.py`                              | `web/favicon.png`, `web/icons/Icon-{192,512}.png`, `Icon-maskable-{192,512}.png` |

All Python tools live in `tools/`. They use a project-local virtual
environment (`.venv/`) so no Python dependencies leak into the Flutter
project:

```sh
python3 -m venv .venv
.venv/bin/pip install cairosvg pillow
.venv/bin/python tools/gen_tiles.py
.venv/bin/python tools/gen_dice.py
.venv/bin/python tools/gen_audio.py
.venv/bin/python tools/gen_icons.py
```

The `assets/svg/` tree is the canonical art pack; `assets/audio/` holds the
short procedural cues. Both are registered as Flutter assets in `pubspec.yaml`.

## Web deployment

The production web app is deployed to Cloudflare Pages. The web shell is a
proper PWA: `web/manifest.json` declares the installable name, theme color,
and icon set; `web/index.html` provides an SVG favicon with PNG fallback and a
brief boot splash to avoid a white flash on cold loads.

```sh
flutter build web --release
npx wrangler pages deploy build/web --project-name=flip10 --branch=main
```

The app also surfaces a soft install prompt (Chrome / Edge desktop and
Android) via a JS-interop hook on `beforeinstallprompt`; the banner only
shows on web and only when the browser has not yet dismissed the prompt.
